# 导航线检测视频结果

本仓库中的视频为倍速合成的导航线检测结果，仅用于直观展示模型效果；视频播放速度不代表模型的实际推理速度。

CNLDNet：模型分割输出结果与原图叠加，以及拟合导航线；
Agri-Binary和Bi-Agri使用相同的二值化图像，即Agri-Binary所展示的

其它场景主要包括未进行数据标注的密集杂草挑战场景，以及车载采集无波动视频。

相关资源：

- **公开数据集**：Hao, Z. (2026). *Navigation Line Detection in agriculture* [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.24252918
